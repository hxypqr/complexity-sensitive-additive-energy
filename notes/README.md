# Research notes

Use this directory for proof sketches, calculations, questions, and project decisions that are not yet part of the manuscript.

Suggested filename format: `YYYY-MM-DD-topic.md`.

Suggested note template:

```text
# Topic

## Claim or question

## Assumptions

## Evidence or derivation

## Dependencies and citations

## Remaining gaps

## Next action
```

Distinguish proved statements, conjectures, computational evidence, and literature claims explicitly.
